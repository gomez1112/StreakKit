# ``StreakKit``

Calculate ordered, generic occurrence, and calendar-period streaks without dependencies.

## Overview

Use ``StreakCalculator`` with explicit ``StreakOptions`` whenever reproducibility matters. ``StreakOptions/default`` intentionally captures the autoupdating calendar and current instant, so its results vary with time and user settings.
